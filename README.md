# Medicine Reminder v1.0

Features: empty stomach / after meal / anytime; 1-4 times a day; edit name, dose, frequency;
suggested times (1h before / 30 min after meals, 30 min between medicines), all editable;
works with phone locked and after restart; Taken and Snooze buttons on the notification.

## Get the APK (no Android Studio needed)
1. Make a free account at github.com, create a new repository (any name).
2. Upload all files from this folder (drag them in; make sure the `.github` folder goes too).
3. Open the repo's "Actions" tab -> "Build APK" -> wait ~5 min -> download "MedicineReminder-APK".
4. Unzip, copy app-debug.apk to your phone, open it, allow "install unknown apps".

## First run on the phone
Allow notifications and "Alarms & reminders". Tap "Reliability" and set battery to Unrestricted.

Not clinically validated: do not rely on it as the only reminder for critical medicines.
